L'obiettivo di questo progetto è implementare una Rete Neurale Convoluzionale da usare per leggere e classificare circa 20000 immagini delle prime 10 lettere alfabetiche. Infatti le Reti Neurali Convoluzionali (Convolutional Neural Network), indicate anche con la sigla CNN, sono un particolare tipo di Rete Neurale principalmente usate per il riconoscimento di immagini.

Perchè si è scelto una Rete Neurale Convoluzionale? La CNN è un tipo di rete neurale artificiale feed-forward in cui il pattern di connettività tra i neuroni è ispirato dall'organizzazione della corteccia visiva animale, i cui neuroni individuali sono disposti in maniera tale da rispondere alle regioni di sovrapposizione che tassellano il campo visivo. Le reti convoluzionali sono ispirate da processi biologici e sono variazioni di percettroni multistrato progettate per usare al minimo la pre-elaborazione. Hanno diverse applicazioni nel riconoscimento di immagini e video, nei sistemi di raccomandazione, nell'elaborazione del linguaggio naturale e, recentemente, in bioinformatica.

In questa rete neurale vengono applicati filtri in modo da riconoscere particolari correlazioni o pattern all'interno dell'immagine stessa, in modo da generare caratteristiche ottimali da fornire come input alla rete neurale (normalmente completamente connessa). Da un punto di vista matematico, l'operazione di convoluzione consiste nel "moltiplicare" tra loro due funzioni opportunamente spostate e calcolare quella risultante (supponiamo che una rappresenti la nostra immagine e l'altra il filtro applicato). Grazie alle operazioni di convoluzione è possibile applicare filtri specifici per estrarre un insieme di informazioni: ad esempio per quanto riguarda il riconoscimento delle immagini, i bordi di sinistra potrebbero essere estratti con il primo filtro, quelli di destra con il secondo, quello superiore bordi con il terzo, ecc . Esso è costituito da 18726 immagini divise in 10 classi, ognuna rappresentante una lettera dell'alfabeto, dalla A alla J. Le immagini sono dei semplici files .PNG, di dimensione 28x28 pixels. def make_confusion_matrix(cf,
                          group_names=None,
                          categories='auto',
                          count=True,
                          percent=True,
                          cbar=True,
                          xyticks=True,
                          xyplotlabels=True,
                          sum_stats=True,
                          figsize=None,
                          cmap='Blues',
                          title=None):
    '''
    ###############################################################################################
    CITATION: taken from: https://github.com/DTrimarchi10/confusion_matrix/blob/master/cf_matrix.py
    ###############################################################################################
    
    This function will make a pretty plot of an sklearn Confusion Matrix cm using a Seaborn heatmap visualization.
    Arguments
    ---------
    cf:            confusion matrix to be passed in
    group_names:   List of strings that represent the labels row by row to be shown in each square.
    categories:    List of strings containing the categories to be displayed on the x,y axis. Default is 'auto'
    count:         If True, show the raw number in the confusion matrix. Default is True.
    normalize:     If True, show the proportions for each category. Default is True.
    cbar:          If True, show the color bar. The cbar values are based off the values in the confusion matrix.
                   Default is True.
    xyticks:       If True, show x and y ticks. Default is True.
    xyplotlabels:  If True, show 'True Label' and 'Predicted Label' on the figure. Default is True.
    sum_stats:     If True, display summary statistics below the figure. Default is True.
    figsize:       Tuple representing the figure size. Default will be the matplotlib rcParams value.
    cmap:          Colormap of the values displayed from matplotlib.pyplot.cm. Default is 'Blues'
                   See http://matplotlib.org/examples/color/colormaps_reference.html
                   
    title:         Title for the heatmap. Default is None.
    '''


    # CODE TO GENERATE TEXT INSIDE EACH SQUARE
    blanks = ['' for i in range(cf.size)]

    if group_names and len(group_names)==cf.size:
        group_labels = ["{}\n".format(value) for value in group_names]
    else:
        group_labels = blanks

    if count:
        group_counts = ["{0:0.0f}\n".format(value) for value in cf.flatten()]
    else:
        group_counts = blanks

    if percent:
        group_percentages = ["{0:.2%}".format(value) for value in cf.flatten()/np.sum(cf)]
    else:
        group_percentages = blanks

    box_labels = [f"{v1}{v2}{v3}".strip() for v1, v2, v3 in zip(group_labels,group_counts,group_percentages)]
    box_labels = np.asarray(box_labels).reshape(cf.shape[0],cf.shape[1])


    # CODE TO GENERATE SUMMARY STATISTICS & TEXT FOR SUMMARY STATS
    if sum_stats:
        #Accuracy is sum of diagonal divided by total observations
        accuracy  = np.trace(cf) / float(np.sum(cf))

        #if it is a binary confusion matrix, show some more stats
        if len(cf)==2:
            #Metrics for Binary Confusion Matrices
            precision = cf[1,1] / sum(cf[:,1])
            recall    = cf[1,1] / sum(cf[1,:])
            f1_score  = 2*precision*recall / (precision + recall)
            stats_text = "\n\nAccuracy={:0.3f}\nPrecision={:0.3f}\nRecall={:0.3f}\nF1 Score={:0.3f}".format(
                accuracy,precision,recall,f1_score)
        else:
            stats_text = "\n\nAccuracy={:0.3f}".format(accuracy)
    else:
        stats_text = ""


    # SET FIGURE PARAMETERS ACCORDING TO OTHER ARGUMENTS
    if figsize==None:
        #Get default figure size if not set
        figsize = plt.rcParams.get('figure.figsize')

    if xyticks==False:
        #Do not show categories if xyticks is False
        categories=False


    # MAKE THE HEATMAP VISUALIZATION
    plt.figure(figsize=figsize)
    sns.heatmap(cf,annot=box_labels,fmt="",cmap=cmap,cbar=cbar,xticklabels=categories,yticklabels=categories)

    if xyplotlabels:
        plt.ylabel('True label')
        plt.xlabel('Predicted label' + stats_text)
    else:
        plt.xlabel(stats_text)
    
    if title:
        plt.title(title)

Risoluzione problema di "Shuffling"¶

Per implementare la K-Fold Cross-Validation (CV) useremo la classe KFold di Scikit-learn. Tuttavia, il mescolamento effettuato dalla classe KFold non effettua uno shuffling efficacie come quello della classe Train_test_split, quindi è necessario uno step preliminare di shuffling più casuale. Per far ciò useremo la funzione shuffle della libreria Scikit-learn. Questo è importante al fine di fornire, durante ogni batch e, ancor di più, durante ogni Fold della CV, un campione abbastanza esplicativo e rappresentativo dell'intero dataset. In caso contrario, le performance del modello ne risentirebbero fortemente, rendendo impossibili la convergenza del modello.

Parte1: Implementazione della Convolutional Neural Network con Pytorch¶

Nel processo di convoluzione abbiamo tre elementi di base:

  • L'immagine in ingresso: una matrice di pixel rappresentativa dell'immagine. In questo esempio: 28x28 per visualizzare un numero, una lettera o un'icona;
  • Il feature detector o Kernel: una matrice che funge da filtro attraverso l'operazione di convoluzione;
  • La feature map: la matrice risultante dalla convoluzione tra l'immagine in ingresso e il kernel;

Alla fine di questo processo, la mappa delle caratteristiche è una matrice, che è più piccola di quella relativa all'immagine di input. Abbiamo perso alcune informazioni sull'immagine in questo passaggio, tuttavia utilizzeremo più filtri di convoluzione (diversi rilevatori di caratteristiche o kernel) per ottenere più mappe di caratteristiche: ognuna di queste memorizzerà le caratteristiche distintive della nostra immagine, ad esempio il contorno giusto, i bordi, i colori più scuri ecc.

Quindi alla rappresentativa matrice di input delle immagini vengono applicati diversi filtri utilizzando operazioni di convoluzione: di conseguenza, otteniamo una serie di feature map. A loro volta, le mappe delle caratteristiche vengono sottocampionate mediante un'operazione di pooling, per ridurre la complessità considerando solo una parte dei dati. È un processo di riduzione dimensionale che ci permette di semplificare la complessità di una CNN. Di solito sono disponibili due tipi di tecniche: max pooling e average pooling. In pratica, le operazioni di calcolo del valore massimo o medio vengono effettuate su un sottoinsieme dei valori della matrice di input. L'obiettivo principale del pooling è ridurre al minimo la complessità, riducendo quindi l'overfitting! Questo processo di convoluzione e sottocampionamento attraverso il raggruppamento viene ripetuto, applicando tra l'altro funzioni di attivazione non lineare alle varie feature map ovvero la Rectified Linear Unit (RELU). Dopo N Convoluzioni, RELU e Pooling, sarà necessario trasformare le nostre feature map raggruppate in un vettore unidimensionale, utilizzando il processo chiamato Flattening (appiattimento). Di conseguenza, potremo inserire il vettore risultante in una rete neurale completamente connessa (fully connected), cioè dove ogni nodo sarà connesso a tutti gli altri: questo è praticamente il livello nascosto della nostra CNN, che si occupa della previsione e classificazione delle immagini. Alla fine del processo raggiungeremo il livello di output, dove tipicamente applicheremo due tipi di funzioni di attivazione per completare la nostra classificazione delle immagini. Useremo la funzione sigmoide in caso di classificazione binaria, o la sua variante multidimensionale chiamata softmax, adatta in caso di classificazione relativa a più categorie.

Come è possibile osservare dalla figura precedente, possiamo anche dividere la nostra rete CNN in due passaggi: il primo contiene i livelli iniziali in cui prepariamo le caratteristiche utilizzando i processi di convoluzione, pooling e flattening. Possiamo anche associare questa serie di livelli al processo di ingegnerizzazione delle caratteristiche (feature engineering process): l'obiettivo è infatti quello di estrarre le caratteristiche dell'immagine che forniremo come input alla rete neurale. Il secondo passaggio consiste in una rete neurale tradizionale, in questo caso completamente connessa, per classificare meglio l'immagine in base alle caratteristiche ricevute in input.

Un altro concetto molto importante è quello di Dropout. Questa è un'ulteriore tecnica adottata per ridurre l'overfitting durante la classificazione che avviene all'interno della rete neurale completamente connessa. Il dropout rimuove in modo casuale alcune connessioni tra due nodi della rete neurale quando i dati di addestramento cambiano.

In questa prima parte di codice, verrà implementata una CNN con 2 strati convolutivi con 5 e 10 filtri, rispettivamente. Ogni strato convolutivo sarà seguito da uno strato di attivazione Relu una Batch Normalization e da un Max-Pooling. Il vettore linearizzato risultante sarà usato per "nutrire" due strati densi che termineranno in uno strato con funzione Softmax il quale fornirà come output un vettore di dimensione 10. Un elemento per ogni classe che il classificatore dovrà valutare.

# Generazione di una classe di CNN con Pytorch.

class Net(nn.Module):
  def __init__(self):
    super(Net, self).__init__()
    self.conv1 = nn.Conv2d(1, 5, kernel_size=5)
    self.b_n_1 = nn.BatchNorm2d(5)
    self.conv2 = nn.Conv2d(5, 10, kernel_size=5)
    self.b_n_2 = nn.BatchNorm2d(10)
    self.fc1 = nn.Linear(160, 50)
    self.b_n_3 = nn.BatchNorm1d(50)
    self.fc2 = nn.Linear(50, 10)

    self.relu = nn.ReLU()
    self.drop_1 = nn.Dropout(0.25)
    self.drop_2 = nn.Dropout(0.5)
    self.sm = nn.Softmax()

  def forward(self, x):
    x = self.conv1(x)
    x = self.relu(x)
    x = self.b_n_1(x)
    x = F.max_pool2d(x, 2)
    x = self.conv2(x)
    x = self.relu(x)
    x = self.b_n_2(x)
    x = F.max_pool2d(x, 2)
    x = self.drop_1(x)
    x = x.view(-1, 160)
    x = self.fc1(x)
    x = self.relu(x)
    x = self.b_n_3(x)
    x = self.drop_2(x)
    x = self.fc2(x)
    return self.sm(x)

def train_CE(X_train, y_train, epoch, bs_train, net, opt, dir_results, tr_ls, tr_ct):
  net.train()

  for batch_idx in range(int(X_train.shape[0]/batch_size)):
    data = X_train[batch_idx*batch_size:(batch_idx+1)*batch_size]
    target = y_train[batch_idx*batch_size:(batch_idx+1)*batch_size]
    # assegnare i tensori ala gpu
    data = data.to(device)
    target = target.to(device)
    # settaggio dei gradienti a zero.
    opt.zero_grad()
    # computazione dell'output della rete
    output = net(data)
    # calcolo dell'errore tramite la funzione di costo scelta.
    loss = F.cross_entropy(output, target)
    # calcolo dei gradienti
    loss.backward()
    # passo di learning (learning step)
    opt.step()

def test_CE(tls, net, X_test, y_test):

    net.eval()
    test_loss = 0
    correct = 0

    # to avoid grandient computation
    with torch.no_grad():
      for test_batch_idx in range(int(X_test.shape[0]/test_batch_size)):
        data = X_test[test_batch_idx*test_batch_size: (test_batch_idx+1)*test_batch_size]
        target = y_test[test_batch_idx*test_batch_size: (test_batch_idx+1)*test_batch_size]
        # put datasets on gpu
        data = data.to(device)
        target = target.to(device)
        # calculate output
        output = net(data)
        ##################################
        test_loss += F.cross_entropy(output, target, size_average=False).item()
        ##################################
        pred = output.data.max(1, keepdim=True)[1]
        correct += pred.eq(target.data.view_as(pred)).sum()

    test_loss /= len(X_test)
    tls.append(test_loss)

    print('\nTest set: Avg. loss: {:.4f}, Accuracy: {}/{} ({:.0f}%)\n'.format(
        test_loss, correct, len(X_test),
        100. * correct / len(X_test)))
    return tls

2. Definizione della CNN

Di seguito entriamo nel vivo della sperimentazione, realizzando una fase di apprendimento e la successiva previsione con una vera CNN. Come libreria di deep learning si utilizzerà Tensorflow come piattaforma di backend e Keras come frontend: quest'ultimo fornisce API (Application Programming Interface) di alto livello, che ci permette di progettare il modello CNN in modo davvero intuitivo.

Implementiamo una rete neurale convoluzionale consiste in un livello di convoluzione con 2 matrici da 64 nodi, ciscuna seguita dalla funzione di attivazione ReLU, uno strato di riduzione dimensionale basato su pooling e dropout. Successivamente, tramite il processo di flatting il risultato è "appiattito" per ottenere il vettore unidimensionale e viene fornito come input ad un livello di rete neurale fully connected composta da 128 nodi applicando ReLU e ulteriore dropout. Il livello di output è costituito da una rete neurale a 10 nodi, lunghezza del nostro array di output con la probabilità che l'immagine contenga i numeri da 0 a 9 (in questo esempio rappresentano la codifica delle lettere dalla A alla J) e dalla funzione di attivazione non lineare softmax.

3. Fit del modello e valutazione tramite Cross validation

Altri due parametri relativi a concetti non ancora illustrati, tipici dei modelli CNN sono epochs e batch_size. Per adattare il modello, l'intero set di dati di addestramento viene fornito come input molte volte, con l'obiettivo di migliorare la precisione. Ogni volta che ripetiamo questa operazione, stiamo correndo un'epoca. La dimensione del batch definisce invece il numero di dati di addestramento elaborati prima dell'aggiornamento dei parametri del modello. Ad esempio, nel nostro caso di CNN i pesi utilizzati per sommare i dati di input relativi a ciascun nodo della rete neurale. Per questa rete neurale convoluzionale abbiamo stabilito che 128 immagini devono essere elaborate ogni volta, prima che l'ottimizzatore della CNN possa modificare qualsiasi parametro.

Il rapporto di classificazione riguarda le metriche chiave in un problema di classificazione ovvero, quante previsioni sono vere e quante sono false. Più specificamente, Veri positivi, Falsi positivi, Veri negativi e Falsi negativi vengono utilizzati per prevedere le seguenti metriche:

  • il recall è la capacità di un classificatore di trovare tutte le istanze positive. Per ogni classe è definito come il rapporto tra i veri positivi e la somma dei veri positivi e dei falsi negativi;
  • la precision è la capacità di un classificatore di non etichettare un'istanza positiva che è effettivamente negativa. Per ogni classe è definito come il rapporto tra i veri positivi e la somma dei veri e falsi positivi;
  • l' f1-score è una media armonica ponderata di precisione e richiamo tale che il punteggio migliore è 1.0 e il peggiore è 0.0. In generale, i punteggi f1 sono inferiori alle misure di accuratezza poiché incorporano precisione e richiamo nel loro calcolo. Come regola generale, per confrontare i modelli di classificazione dovrebbe essere utilizzata la media ponderata di f1, non l'accuratezza globale;
  • il support è il numero di occorrenze della classe data nel set di dati.
